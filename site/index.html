Features

Everything You Need

Built from the ground up for media professionals who demand performance and reliability.

Smart Grid Layout

Configurable 1×1 to 6×6 grids. Up to 36 concurrent video cells with lazy loading and priority-based loading.

Advanced Playback

Fullscreen player with keyboard navigation, playlist modes (sequential/shuffle), and auto-resume functionality.

Audit System

Track reviewed files with SQLite-backed persistence. Context-aware auditing prevents race conditions.

Favorites & Playlists

Mark important files with ❤️ hearts. Filter by favorites and play them as a dedicated playlist.

Powerful Search

Instant search by filename or folder path. Press / to open, results filter in real-time.

Secure Deletion

Secret code-based authorization with 30-day cookie persistence. Two-stage confirmation prevents accidents.

Performance

Built for Speed

Every aspect optimized for handling large media libraries with thousands of files.

⚡

Media Element Pooling

48 reusable video/audio elements prevent DOM thrashing and reduce memory usage by 80%.

🎯

Lazy Loading

IntersectionObserver loads videos only when visible. 200px viewport margin for smooth scrolling.

🌊

HTTP/2 Multiplexing

Stream multiple videos over single connection. Solves Firefox's 6-connection limit.

🛡️

Smart Throttling

50MB/s sustained rate after 10MB burst. Protects 5400 RPM drives while maintaining performance.

How It Works

1

Upload Your Media

Place files in the ./volumes folder or mount your existing media library. Supports MP4, WebM, MKV, MOV, MP3, WAV, OGG, and common image formats.

2

Configure Your Grid

Choose your layout (1×1 to 6×6) and start browsing. The grid automatically adapts to your screen size with responsive design.

3

Manage & Organize

Audit files as you review them, mark favorites with ❤️ hearts, use powerful search with /, and filter by status.

4

Stream & Enjoy

Click any media for fullscreen playback. Videos auto-play, keyboard navigation works seamlessly, and playback position is remembered.

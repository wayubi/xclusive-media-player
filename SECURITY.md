# Security Policy

## Supported Versions
We provide security updates for the following versions of `xclusive-media-player`:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Previous | :x:                |

*Note: We recommend users stay on the latest stable release to ensure they have the most recent security patches.*

## Reporting a Vulnerability

We take the security of our users seriously. If you discover a security vulnerability in `xclusive-media-player`, please do not open a public issue.

### How to report:
1. **Email:** Please send a detailed description of the vulnerability to **wayubi@gmail.com**.
2. **GitHub Issues:** You may open an issue ticket on the repository, but **please do not include sensitive details** (like exploit code or specific account data) in the public description. Use the issue to provide a high-level summary and ask the maintainer to contact you privately.

### What to include:
To help us fix the issue as quickly as possible, please include:
* A description of the vulnerability.
* Steps to reproduce the issue.
* The impact of the vulnerability (e.g., "allows unauthorized access to files").
* Any potential workarounds you have found.

### Our Response Process
Once a report is received, our team will:
1. **Verify:** We will attempt to reproduce the issue in a private environment.
2. **Fix:** We will develop a patch to address the vulnerability.
3. **Advise:** Once the fix is released, we will publish a Security Advisory to notify the community.

We aim to acknowledge all reports and provide a fix as soon as possible.
